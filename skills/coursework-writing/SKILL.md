# 课程作业写作与核验

本技能是所有课程作业的默认入口，适用于两位学习者、各学期及不同项目目录中的初稿、续写、改写和审阅，无需用户再次提醒。按交付物和文本语言执行适用检查；纯代码与计算保留专业验收。

## 先确定正在处理哪一稿

读取项目AGENTS.md、题目、rubric、教师模板及已确认的公司、题目和分工。写作、润色、标点、审计与核验流程以本技能为准；正式库的`学习笔记/作业与代码项目工作流.md`只维护代码技能路由和库内登记规则，不重复本技能内容。

用户指向“昨天的稿”“另一个模型的稿”时，先定位真实文件、日期和版本。保存原件与哈希，另存派生改写稿。保留可核实事实；来源失真、论证不成立或偏题时，记录问题后从真实来源重写对应部分。仅在缺少会改变结果的信息时询问，并继续不依赖回答的工作。

## 要求与格式验收

开始写作前，把真实题目、最新教师说明、rubric与模板转为可核验清单：要求／来源页码或链接／正文或文件定位／核验结果。来源冲突并列记录，缺少题目或格式时标“待核”，继续完成不依赖缺失信息的工作。

- 内容：具体问题与任务动词、必写章节、评分权重、个人或小组范围、已确认分工、允许的AI协助及披露要求。
- 篇幅与文件：字数或页数限制及计数口径、文件类型与命名、必交附件；实际统计正文，不能用预算或大纲字数代替。
- 版式：教师规定的字体字号、行距、页边距、封面、目录、标题层级、页码、图表编号与说明。没有公布的参数保留待核，不把自选样式写成教师要求。
- 小标题：作业正文的小标题默认用正文字号加粗、独立成行，不加项目符号、编号圆点或其他列表标记。教师模板、rubric或目录要求指定了标题样式或层级时以其为准，并在核验表“格式与篇幅”写明依据。
- 引用：指定引注格式、文内引注与参考文献双向对应、原始来源与页码、直接引文及转述边界；不以模式检测代替查证来源。

教师要求的结论、标题、表格或固定句式优先于通用润色偏好。Word/PDF按对应文档技能渲染逐页检查；PPT按演示文稿技能检查页序、溢出与可读性，讲稿做适用文字检查；纯文本可检查结构和字数，字体与分页没有实际载体时标不适用。

## 引用格式与可点击链接

每份作业按教师指定的引用体系及版本统一作者、日期、标题、出处、卷期页码、大小写、斜体、排序和缩进；文内引注与参考文献双向核对。未说明体系时标待核，不把自选格式称为教师要求。

- 为引用体系要求或适合保留的DOI、网页与在线报告设置真实超链接；有已核实DOI时使用对应doi.org解析地址，无DOI不补造。显示文字、实际目标与所引版本一致，链接指向能支持论点的原文，不以搜索结果页代替来源。
- Word使用原生超链接或书签字段，PDF导出后检查链接注释与目标，Markdown保留正确链接语法；不能只把文字变蓝或留下未转换的Markdown。文内引注跳转参考文献、目录及交叉引用仅在提交格式允许或要求时设置，教师固定模板优先。
- 标点与网址边界逐项检查，不能误把末尾句号、括号或断行空格写进目标；保留有效的路径、片段和必要查询参数，不改动DOI及文献题名。检查真实目标、来源标题／作者／日期及内容对应，HTTP成功状态本身不算来源核验通过。
- 付费、学校登录或访问受阻的来源保留准确文献信息和稳定地址，记录访问限制；不导出个人本机路径、临时下载链接或带登录凭据的地址，不把未打开的链接记为已访问。
- 在最终DOCX/PDF/PPT等交付文件中核对原生链接目标与内部书签是否存在，导出后重新检查；有条件时实际打开点验。结构验证、目标页面访问和应用内点击分别记录，失败、登录受阻或未实测如实标明。

## 每份文字作业的默认处理

按改动大小决定检查强度：

| 改动 | 例子 | 执行 |
| --- | --- | --- |
| 整篇 | 初稿、其他模型稿件的改写、交付前审阅 | 走完本节全部步骤，含信号审计和A参考解释 |
| 局部 | 改一段、调格式、修引用，且不是本次交付 | 只对改动部分做要求核对、事实与引用核验、润色和标点；跳过信号审计和A参考解释，并记录“本次跳过，待终稿” |

交付前的终稿必须按“整篇”再跑一次，所以每份作业至少有一次完整检查。

1. 按上方清单把评分要求与正文、来源和最终文件逐项对应。区分来源事实、本文分析、目标、已发生结果及未知项。使用实际报告期和主体范围，不以其他模型的文字替代原始证据。遵守课程明确的AI使用规则，不编造引用、实验数据、测试结果或个人经历。
2. 英文正文读取并使用[humanize-writing](../humanize-writing/SKILL.md)。改写时按该技能读取模式参考；用具体事实和必要分析组织段落，保留专业术语、数字、引文、链接和判断强度。表达匹配本科课程任务与本人已有写作样例，统一拼写习惯，保留本人的分析和观点。
3. 有中文说明或学习笔记时读取并使用[humanizer-zh](../humanizer-zh/SKILL.md)。没有中文段落时记录不适用，不把它当作额外英文改写器。
4. 润色后按下方“标点复核”逐项检查；脚本无提示不能替代这一步。
5. 读取并运行[ai-writing-signal-audit](../ai-writing-signal-audit/SKILL.md)，每份文字作业保存最终正文的统计和其调用的humanize-writing模式检查。改写任务另保存原稿正文结果，以相同范围和方法对比。
6. 复核改写后的事实、引用、范围、实际字数、格式及rubric；完成适用的渲染检查，交付派生文件与下方核验表。正文后续有实质变化时重新检查受影响项，并对最终正文重跑审计。

代码、公式、表格和老师固定模板只做各自适用的验收，不为凑检查数量改写它们。纯代码或纯计算没有可审计自然语言时，写明信号审计不适用。

## 标点复核

英文正文按英文标点、中文解释按中文标点检查，双语内容逐段判断，不全篇替换。检查中英文符号误混、引号和括号配对、英文标点空格、重复或多余符号、断句，以及同类标题、列表、表格和图注的一致性。

引文、教师原模板、代码、公式、标识符、网址和链接目标保留原内容；参考文献按指定引用格式单独核查，不套用正文标点规则。连字符、范围连接号、负号、小数点、缩写和省略号按语义判断，来源中的疑似错误记待核。

每处修改回看完整句，复核原意、事实、数字及引用；Word/PDF修改后检查渲染、换行和页数。记录实际检查范围、修改项与未检查／待核项，跳过的部分不写通过。标点问题不是AI写作证据，不据此报告AI百分比。

## A参考技能的默认接入

每份文字作业默认只读取[A参考摘录](references/a-reference-excerpt.md)，它逐字收录了研究参考的“C. Praktische Checkliste”和“8. Wichtige Einschränkung”两节，用于解释实际发现的写作信号、文本长度及适用的误判限制。[ai-text-detection](../ai-text-detection/SKILL.md)正文和[研究参考](../ai-text-detection/references/ai-text-detection-research.md)全文不默认读取；问到具体检测器、准确率、水印、需要文献，或摘录不足以解释某个信号时，再读相应章节，不整份通读。检查记录写明本次读的是摘录还是原文章节。

A提供定性参考，本地ai-writing-signal-audit提供统计；共享模式只记录一次，不包装成两个独立检测结果。检查记录说明实际采用的参考章节、具体文本依据及限制。上游参考中的研究数字、可靠性评分及其他具体结论需回查原始来源；未核实不作为已证实事实。教师要求与已确认的引用、术语和本人观点继续优先；不因一般风格信号删除必写内容，也不由信号推断作者身份、本人掌握或学校检测结果。

## 运行与解释检查

将实际提交正文单独提取为UTF-8文本，再运行：

```bash
python3 ../ai-writing-signal-audit/scripts/audit.py /absolute/path/body.txt --json
```

上述相对脚本路径以本技能目录为基准；实际运行时解析为已存在的绝对路径。保存工具输出、版本或脚本哈希、输入范围及检查时间。审计已经调用`humanize-writing/scripts/ai_pattern_lint.py`时，记录为一项共享检查，不将其包装成两个独立检测器。

参考文献、附录原文摘录、封面、教师固定模板和中文说明不混入英文正文节奏统计。人工核对缩写、引用中的句点是否被误当作断句；有误分时写明限制，不把粗分句结果当精确语言分析。中文字数和句长不套用英文按空格计词指标。

审计提供的是模式命中数、每千词密度及节奏统计，不能测出AI生成百分比。交付只报告实际运行结果；没有真实第三方检测时写“未测得第三方AI率”，不编造零AI率，也不预测Turnitin等服务的结论。润色以表达清楚、论证成立为目标，不能围绕分数反复改写、故意制造错误或篡改引文。

现有工具本地运行。课程资料与私人稿件外发继续遵守项目已确认的授权范围，使用工具本身不等于授权把整份稿件上传给新的服务。

## 交付核验表

每次交付都附简短核验表，与提交正文分开。各项填写“通过／未通过／待核／未执行／不适用”及证据定位；空白、不可读或未运行的项目不能写通过。

| 项目 | 记录的证据 |
| --- | --- |
| 题目与rubric | 真实要求、对应章节、遗漏与冲突 |
| 格式与篇幅 | 实际字数及口径、文件参数、小标题样式及依据、渲染范围或不适用原因 |
| 代码与测试 | 代码目录、真实命令与结果、未验证项；无代码写不适用 |
| 事实与引用 | 原始来源、指定引用体系、引注对应、仍待核的论断 |
| 引用超链接 | 显示文字与真实目标、DOI／网页、导出后链接及内部跳转验证、访问限制 |
| 自然表达 | 实际使用的英文／中文技能、保留的术语与本人观点 |
| 标点与语法 | 检查范围、确认的修正、保护的引文／代码／公式 |
| 写作信号 | 最终正文路径与哈希、真实统计、共享模式检查、A参考章节与定性解释、脚本哈希及限制 |
| 本人与提交 | AI协助范围、本人仍需掌握或补充的内容、提交凭证或未提交状态 |

阶段性大纲或局部修改按已完成范围报告，其余待核；完整作业交付前逐项核验。第三方检测工具在用户选定后接入；涉及资料外发时另核授权。保存原报告、工具版本、文本范围和限制，其分数不作为反复改写目标。

## 完成时留下什么

- 可编辑的派生稿与原稿位置；引用、摘录及专业事实保持可追溯。
- 实际检查范围、英文与中文技能适用情况、标点复核、信号统计和工具限制。
- AI协助范围、本人仍需理解或补充的内容、导师要求及提交状态。文件就绪、本人掌握和已提交分别记录。

当正文满足题目、引用复核及必要格式检查，且审计结果或明确限制已记录，即可交付。未运行的检查如实标明，不以无限重写追逐某个信号值。
