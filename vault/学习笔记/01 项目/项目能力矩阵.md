# 项目能力矩阵

## 六类通用能力

| 能力 | 含义 | 可观察结果 |
| --- | --- | --- |
| 理解与提取 | 不看资料讲清核心概念 | 正确率、遗漏、解释质量 |
| 分析与判断 | 识别问题类型、区分线索与有效证据 | 判断理由、反例、边界 |
| 执行与交付 | 按期限完成可验收的成品 | 成品、期限、返工次数 |
| 表达与沟通 | 让别人看得懂、用得上 | 可理解性、反馈、修改记录 |
| 复盘与迁移 | 换题、换环境后仍然有效 | 延迟复测、跨场景表现 |
| 自我管理 | 时间、注意力、边界和停止条件 | 计划兑现、停止记录 |

## 使用方法

1. 一个项目同时最多训练两项主要能力。
2. 新训练先用 [[项目能力闭环]] 建档，先测基线再学习。
3. 项目页面保存任务细节；能力实验页保存跨项目复测结果。
4. 每周蒸馏只更新发生变化的行，不为保持活跃强行制造进展。
5. 同一能力在两个以上项目中重复有效，才考虑是否形成个人规则。
6. 新项目使用 [[通用项目]] 建档；可选模块是否参与周报，以 [[_系统/模块配置|模块配置]] 为准。
7. 本人结果先进下方“证据记录”，每周蒸馏再据此更新“当前项目”表里发生变化的行。
