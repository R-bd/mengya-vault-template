# 项目注册表

这里是项目的统一入口。项目由现实需要产生，不要求长期固定。状态、阶段和下一次验证只在各项目页的属性中维护；下方链接是无插件时也可用的入口。

## 通用项目自动列表

需要 Dataview 插件；没有插件时这一段不显示，上表仍可用。

```dataview
TABLE 项目名称, 状态, 当前阶段, 主要能力, 下一次验证
FROM ""
WHERE record_type = "project" AND 纳入成长系统 = true
SORT 状态 ASC, 项目名称 ASC
```
