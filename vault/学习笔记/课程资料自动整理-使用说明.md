# 课程资料自动收集与整理

本页给人看：怎么建课、怎么手动触发、怎么启用周检。AI 的执行步骤、结果结构和输出标准都在 [[学习笔记/课程资料周检-Prompt|课程资料周检]]，入口是 [[学习笔记/课程资料流水线|课程资料流水线]]。

## 这套流程能做什么

这套流程用于每周检查新开放的 Course Plan、Lecture、Tutorial、Lab、Assignment、Quiz 和 Midterm 通知；保存原始文件后，整理课程重点、考核范围、作业完成步骤、资料缺口与下一步行动。

流程分成两层：

1. **收集层**：从 学校教学平台 下载新资料。它需要你的有效登录状态、课程页面地址和浏览器访问权限。
2. **整理层**：扫描已经下载到本地的课程资料，比较新增/替换文件，并更新 Obsidian。文件进入本地后可按 Prompt 执行；是否已启用定时任务、是否稳定运行，须以实际配置和运行记录核验。模板就绪不代表自动化已经运行。

没有登录态时，自动化不会声称已经检查 学校教学平台，只会报告“未执行远程收集”，然后整理本地已有资料。

## 已准备的模板

- [[课程主页]]：一门课的总导航、考核总览和资料缺口。
- [[课程计划]]：Course Plan、CLO、考核占比和教学周计划。
- [[每周课程整理]]：每周新增文件、课程重点、Tutorial/Lab 方法和考核关联。
- [[课程作业]]：逐项拆解作业要求、rubric、完成步骤和提交自检。
- [[课程测验]]：Quiz、Midterm、Final 的范围、复习方法、错题和考后回填。

## 下学期开学前需要提供一次的信息

1. 学期名称，例如 `2027-01`。
2. 开学日期和教学周数。
3. 每门课程的课程代码、课程名和 学校教学平台 页面地址。
4. 希望每周检查的时间。
5. 若要自动从 学校教学平台 下载：在指定浏览器中登录，并明确授权 Codex 操作这些课程页面。

不要把密码写进 Obsidian、Prompt 或自动化配置。

## 建课方法

对 Codex 说：

> 建立下学期课程：学期是____，课程有____。按课程资料自动整理模板建档；原始资料保持只读，未知日期和占比标记待公布。

Codex 会为每门课建立课程主页和课程计划页，不会提前生成虚构重点。

## 每周手动触发

资料已经下载到收件箱后，对 Codex 说：

> 整理本周课程资料。扫描所有进行中课程，只处理新增或被替换的文件；更新每周重点、作业、小测和期中页面，并列出资料缺口。

## 自动化启用方法

学期日期与检查时间确定后，对 Codex 说：

> 启用下学期课程周检。学期从____到____，每周____的____执行，使用《课程资料周检-Prompt》。如果无法访问 学校教学平台，只整理本地资料并明确报告远程收集未执行。

对应 Prompt：[[课程资料周检-Prompt]]。

作答与反馈规则见 [[学习笔记/学习反馈与复测规则]]。

## 课表与日历接入

个人课表、学期起止、官方学期日历和考核通知同样可放入收件箱。收到这些资料时先执行 [[学习笔记/课程日程整理-Prompt]]，建立每日安排并导出 `.ics`。入口和边界见 [[学习笔记/课程日程与Apple日历]]；资料变化才更新对应日程，官方安排与建议计划分开。
