# 学习反馈与复测规则

遵守 [[_系统/共同规则|共同规则]]。目标是通过本人作答发现薄弱点。

## 每次学习怎么走

作业：读取题目、rubric、期限和 AI 使用要求 → 对应来源并完成草稿 → 核对事实、引用及运行结果 → 检查提交格式 → 由本人确认实际提交状态。提交正文保持英文，中文用于解释。

复习：确认范围来源 → 不看答案独立尝试 → 保存本人原始作答 → 评分并记录错因 → 针对训练 → 换一道同类题延迟复测。AI 辅导发生在作答之后；需要提示时保留提示记录，不能当作独立完成。

范围来源仍按老师通知优先，其次本学期 Course Plan 的“课程计划推定范围”，两者缺失则待公布。真题频率不能扩大范围。没有官方答案时保留 Suggested answer 或推断标记；OCR、AI 推断和本人答案分别标明。

错因可以记为概念、步骤、英文理解、时间分配或待判断。原因以答卷和本人反馈为依据；不要从一次错误直接推断能力。资料缺口记录缺失文件与获取状态，掌握问题记录独立作答结果，两者分开。

每周先将旧行动标为完成、延期、取消或无法判断，再决定是否继续。笔记数、卡片数和勾选数只表示记录或行动状态；能力变化需要本人基线与复测结果。

当前优先行动先按已确认的课程、期限和实际进度选择；旧基线和往届资料只作候选，不自动续期。资料缺口与掌握问题分开记录：前者写缺失文件和获取状态，后者必须指向本人答题、解释或实践结果。没有作答证据时写“尚未测量”。

复习先独立尝试，再看答案或让 AI 补充笔记。错题按概念、步骤、英文理解或时间分配记录原因，并安排对应训练与延迟复测。Anki 优先收术语、判断条件和反复忘记的知识点；长计算和完整论述留作练习。

课程结束后保留资料和结果，退出当前行动列表；需要补修时再确认。原始种子保持只读，不改写本人答卷、成绩或感受。课程关闭时停止主动读取和维护。课程页保存正文，首页、周报和看板只保存导航与行动，避免重复维护。

## 从本人结果收件箱接收

本人把结果放在 `10 原始种子/00 收件箱/本人结果/<学习者>/`：截图、回执、成绩、老师反馈、答卷，或在 `随手记.md` 里写一行。用法见 [[10 原始种子/00 收件箱/本人结果/说明|本人结果收件箱]]。这里的内容由本人主动投放，可以读取；“不读取成绩和学生提交”的限制只针对从学校网站采集。原件只读，不改写、不移动。

每次按文件哈希和随手记的行内容找出新增项，已处理的不重复处理。课程或作业归属不明的列为待确认，不从文件名猜。然后按证据类型处理：

| 本人投放的 | 能证明什么 | 怎么处理 |
| --- | --- | --- |
| 随手记里的一句话 | 本人告知，未见凭证 | 状态记“本人告知”，写明缺哪种凭证 |
| 提交页截图、回执 | 已提交 | 记录平台和实际时间，状态改为已提交，在作业执行卡链接原件 |
| 成绩、老师反馈 | 结果与反馈 | 记入作业页，按上文走错因与训练；不由一次成绩推断整体能力 |
| 本人答卷 | 独立作答 | 评分、记错因、安排延迟复测，注明闭卷与 AI 帮助情况 |

截图看不清或信息不全时，只记录能确认的部分，其余待核。有个人任务状态文件（`_系统/<学期><学习者>个人任务状态.json`）的学习者，提交状态同步到其现有字段；没有状态文件的，结果只挂到对应作业页。处理后按 [[_系统/交接/说明|交接说明]] 追加一行，技能名写“本人结果”。

带凭证的结果（回执、成绩、反馈、答卷）同时在 [[项目能力矩阵#证据记录|项目能力矩阵的证据记录]]末尾追加一行：日期、项目、能力、本人结果、等级、证据位置、还缺什么。只有随手记一句话的不追加。矩阵上方的“当前项目”表不在这一步改，留给每周蒸馏。
