# 课程资料周检 Prompt

统一入口：[[学习笔记/课程资料流水线|课程资料流水线]]。本页执行课程资料整理与周检分支。

先完成流水线的前置检查（模块开关、学习者归属、学期与课程状态）。

装了子代理时，周检先为每位学习者各派一个 `course-source-scout` 并行侦察（只读，见 [[_系统/技能地图#子代理|技能地图]]），主对话拿到清单后再按下文整理和写入。子代理不运行采集命令；需要先采集时由主对话或定时任务完成。没装或派不出来时照原流程执行。

先读取每门课的课程主页、课程计划和上一次资料变更记录。如果本次任务已获得 学校教学平台 页面访问权限和有效登录态，逐门检查课程页面，只下载新开放或已更新的 Course Plan、Lecture、Tutorial、Lab、Assignment、Quiz、Midterm 与老师通知；如果没有访问权限，明确写出“远程收集未执行”，只扫描本地 `10 原始种子/00 收件箱/` 中的新增或变更文件。不得声称检查了未实际打开的页面。

通过文件名、修改时间、大小和必要的内容比对识别新增或替换资料。老师更新同名文件时，在结果中保留版本变化说明。

对每门有变化的课程：

1. 更新课程主页的最近扫描日期、考核总览、资料缺口和本周唯一行动。
2. Course Plan 或考核规则发生变化时，更新课程计划页，并标注原文件与位置。
3. 使用《每周课程整理》记录新增资料、课程重点、Tutorial/Lab 完成方法和 Assignment/Quiz/Midterm 关联。
4. 发现新作业时，使用《课程作业》建立执行卡：照录要求，拆解 rubric、步骤、验收和提交规则；不替用户编造内容或结果。
5. 发现 Quiz、Midterm 或 Final 通知时，使用《课程测验》建立复习卡：官方范围与推断严格分开。
6. 每个重点必须附文件名和页码、题号或通知位置；OCR 内容标记可能有误。
7. 更新资料变更记录；没有变化的课程只记录“本周无新增”，不要重复生成页面。

最后汇总：实际检查范围、新增/替换/待开放资料、临近截止项目、需要用户确认的问题，以及下一周前唯一优先行动及其验收结果。资料缺口与本人掌握问题分开列出；没有本人作答写“尚未测量”。旧基线不自动续期；缺少当前期限或进度时先列待确认项，不强行选定课程。保持中英术语对照，中文解释为主。


## 每门课程的结果结构

```text
学习笔记/01 项目/课程/<学期>/<课程代码 课程名>/
├── 00 课程主页.md
├── 01 课程计划.md
├── 02 每周重点/
├── 03 作业/
├── 04 小测与期中/
├── 05 错题与反馈/
└── 99 资料变更记录.md
```

原始文件仍放在 `10 原始种子/00 收件箱/` 对应课程目录，保持只读。Obsidian 结果页只引用它们，不覆盖原文件。

## 每周输出标准

每次运行必须报告：

- 哪些课程页面实际检查过；
- 新增、替换和仍未开放的文件；
- 本周重点及其文件、页码或题号来源；
- 新作业的要求、rubric、截止日期和完成步骤；
- Quiz/Midterm 的官方范围与待确认项；
- 原始资料是否保持不变；
- 下周前唯一优先行动。

## 边界

- 不把往届资料自动当成本学期范围。
- 不根据文件名猜测考试重点。
- 没有官方答案时，推导内容必须标记“无参考答案，此为推断”。
- 老师更新文件时保留版本变化，不静默覆盖结论。
- 作业方法可以拆解和辅导，但不能伪造实验结果、个人经历或提交凭证。

## 接续其他阶段

若新增资料包含个人课表、学期日历、考核日期或提交期限，按 [[学习笔记/课程日程整理-Prompt]] 更新该学期日程。Course Plan 或教学资料变化影响建议学习任务时更新对应任务；课程知识正文仍留在原课程页。复用课程日程处理状态，避免日检与周检重复导出。

每次检查下一教学周的预习窗口，即使本周没有新文件，规则见 [[学习笔记/每周双语预习与考核标注]]；缺少学期或周次锚点时保留待排周，同一周且来源无变化不重复生成。

启用 Anki 的课程新增或更新卡片前，执行 [[anki/考试复习/README#每门课程的 Anki 模板选择流程]]；周整理只链接选型记录。
