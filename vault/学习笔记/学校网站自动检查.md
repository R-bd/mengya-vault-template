# 学校网站自动检查

统一入口：[[学习笔记/课程资料流水线|课程资料流水线]]。本页维护网站身份核验、来源覆盖与采集细则。

模板不附带采集程序。登录方式、验证码和访问限制每所学校都不同，请自备采集方式，并先确认学校的使用条款允许。下面是这一步应该守住的规则。

## 覆盖范围

| 学习者 | 本学期课程 | 已核验来源 |
| --- | --- | --- |
|  |  |  |

只写实际核验过的来源。没渲染出来的历史消息、没打开的频道和文件区，写“未覆盖”，不能声称全部资料已收齐。

## 每次处理

1. 先遵守模块开关与学习资料归属；课程学习关闭就停止浏览器与课程读取。
2. 每位学习者使用各自隔离的本机会话，核对账号姓名、课程代码和学期。密码只由本机钥匙串交给登录程序，不出现在聊天、日志或笔记里；验证码和 MFA 由本人处理。
3. 下载课程页实际提供的文件；用文件哈希识别相同内容，同名更新另存版本。失败项目保留待重试，不标成成功。压缩包保留原包，展开和整理另行核验。
4. 读取课程公告，保留原文、来源、作者、发布时间和修改版本。缺字段不补造；解析到零条不能写成“老师没有发通知”。只按本人的组别处理停课、补课与提交日期。
5. 下载后先新增到 `10 原始种子/00 收件箱/课程资料/<学习者>/<学期>/<课程>/<网站>/`，再执行课程整理流程；已有原始种子仍只读。下载和整理分开登记状态。
6. 新通知先更新课程计划唯一正文，再同步相关计划、预习和日程；有确切时间才生成新版日历文件。

## 只读边界

只读已授权的课程来源。不读取私人聊天、成绩、他人名单、学生提交或测验作答；不代发消息、已读、表情、登记或作业。一个人的连接不能当作另一个人的访问权限。

## 采集频率与登录

- 每日轻量检查课程页和公告，课程页有变化或每隔几天再做一次完整文件核对；给每门课设请求上限，请求之间留随机间隔。
- 登录只自动提交一次；出现验证码即停下等本人处理；登录失败、限流或封禁后冷却数小时，期间不重试。
- 每次运行的访问量写入本机日志。

## 需要本人操作时

说明“哪位学习者、哪个网站、需要点什么”，打开对应窗口，等本人完成后再核对结果；不在聊天里索取密码或验证码。其他已登录账号可以继续。已知缺口不每天重复催促。

## 通知原则

有新增或更新资料、重要日期变更、首次需要本人操作或执行失败才通知。没有实质变化保持安静；不把失败、未核验或账号串用当作无更新。
