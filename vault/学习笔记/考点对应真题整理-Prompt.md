# 考点对应真题整理 Prompt

## 直接复制使用

```text
请为课程【课程代码 / 课程名】整理“考点对应题目与参考答案”。

课程项目：【已有课程主页链接；没有则新建一门课一个项目】
本次考点提示：【优先粘贴老师提示或填写 exam-scope；老师未提供时，填写本学期 Course Plan / 课程计划链接】
往年期末卷目录：【路径】
检索年份：【指定年份；留空表示全部已提供往年卷】
讲义与 Tutorial 目录：【路径】

按 Obsidian《考点对应题目与参考答案》模板完成：
1. 先核对课程代码、名称、范围版本和原卷清单；代码不一致时先确认。
2. 按来源优先级确定唯一范围正文：老师最新通知或明确提示优先；老师未提供时，按本学期 Course Plan 的教学周主题整理“课程计划推定范围”；两者都没有则标记“待公布”，不自行生成范围。给了讲义页码就严格逐页匹配，不能把整章都算范围内。往届范围、旧题和出题频率不能反向定义或扩大范围。
3. 逐份查看指定年份原卷，恢复题号、原卷页、分值、题目要求和完整案例条件。已有答案只作为线索，不能代替原卷核对。
4. 建立考点对照表，每个英文考点后附中文含义；区分直接对应、范围内应用、部分对应、相关延伸和未找到。只保留对应的小问；未找到也逐项列出。
5. 每道题按“英文题目/题意摘要 → 中文题意 → 英文参考答案 → 中文参考答案”排列，中英文逐点对应，不用一句中文概括代替多点答案，也不把所有题和所有答案拆成两份。写清对应讲义文件和物理页码。原题转录与压缩题意明确区分；密文、明文、密钥、命令、代码、算式和计算数据不得翻译改写。
6. 根据 State/List/Explain/Discuss/Evaluate 和分值控制作答深度：列举题列足点数；解释题每点有含义或作用；案例题结合题设；计算题写完整步骤并独立验算。
7. 先检查 Lecture / Tutorial / Lab 是否有可确认的老师标准答案或课程讲义已给答案。若有，替换相应 `Suggested answer`，改标为 `Teacher answer / 老师标准答案` 或 `Lecture answer / 讲义已给答案`，并附文件、页码/题号。无教师批注、评分或来源标识的同学作答不得冒充标准答案。没有官方答案时标记“无官方参考答案，此为根据课程资料推断”。讲义缺失、扫描模糊、术语歧义、疑似错字和算法假设单独标记待核；不要猜成确定答案。
8. 若课程范围内出现计算、加密、换算或规则转换题，必须为每一种方法另建“计算题训练”：用中文详细解释公式、符号、单位、字母编号、矩阵方向、补位等约定；给一题完整例题及逐步解法；再给一题不同数据的测试题；最后在独立区块提供测试题参考答案。所有结果须另行验算。以后处理任何有计算题的科目都执行此步骤；没有计算题则注明未发现，不硬造题型。
9. 若 Section B（或同类部分）要求 Q4/Q5 任选一题，逐年比较两题的主题、小问、范围覆盖、资料完整度、难度和稳定性；给出“主记题号、备用题号、各自最低记忆包、考场改选规则”。推荐必须依据实际原卷，不得把复习优先级写成考题预测，也不得要求考生无视当次更熟的题。
10. 一门课程只保留一个项目。已有项目就继续用；没有项目才按《课程主页》模板建立。未知学期写“待确认”。
11. 课程计划页维护考试范围的唯一正文；考点题答页只引用范围，并保存考点、真题与答案。新课程结果保存在项目内 `06 期末复习/`；已有考试复习项目沿用既有目录。将最终文件加入课程项目的“期末考点与历年真题”入口。
12. 原始资料只读。修改现有导航或模板前备份，保留用户内容。核验文件确实写入活动 iCloud Obsidian vault，并检查链接能解析。

交付：课程项目入口、考点题答文件、对应题数量、已检索试卷、实际核验内容和未完成/待核项。不要用未检索年份计算频率或宣称必考。
```

## 使用约定

- 一门课一个课程项目；同一课程已有项目就继续用，不重复建课程主页。
- 在 Obsidian 命令面板使用“模板：插入模板”，选择 `_模板/考试复习/考点对应题目与参考答案`。
- 模板不会自动读取 PDF 或生成答案；把上述提示词与课程信息交给助手后才执行整理。
- 同一课程不同学期可各建项目；同一学期的资料和答案更新到同一项目。
- 老师未提供考试范围时，只能使用本学期课程计划生成“课程计划推定范围”；老师后续公布范围后，以最新通知为准并记录变化。
