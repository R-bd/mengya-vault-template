# 引导问题

不知道写什么的时候，按当下的情况挑一组，回答其中两三个就够，不用全答。问题是按下面几个公开的反思方法用自己的话改写的，方法本身有出处，但对你是否有效还没有验证，所以这页记为 E1。哪组问题用了之后真的帮你写出东西，在页尾记一笔。

## 今天没什么可写（两分钟）

1. 今天哪一件事占用的时间或心思最多？
2. 做这件事的时候，我的第一反应是什么？
3. 明天如果只能推进一件事，是哪一件？

## 刚发生了一件让我有情绪的事

按“发生了什么 → 这说明什么 → 接下来怎么办”三步走。

1. 发生了什么？只写看得见、听得见的部分，先不写评价。
2. 我当时的感受是什么？身体上有什么反应？
3. 这件事为什么会让我有这种反应？它碰到了我在意的什么？
4. 有哪些部分其实进展得不错？
5. 下次遇到类似情况，我想试的一个不同做法是什么？

## 刚做完一件事，想复盘

1. 我原本打算做到什么程度？
2. 实际做到了什么？有文件、成绩或回执可以证明吗？
3. 两者的差距主要来自哪里：准备、时间、理解，还是别的？
4. 下次保留哪一个做法，改掉哪一个做法？

## 想定一个目标，或者总是拖着不动

1. 接下来这段时间，我最想实现又确实有可能做到的一件事是什么？
2. 做到之后，最好的结果是什么样子？
3. 最可能拦住我的，是我自己身上的哪一个习惯、情绪或想法？
4. 把它写成一句“如果出现……，我就……”。

## 要做一个决定

1. 我有哪几个选项？不做任何改变也算一个。
2. 我现在倾向哪一个？真实的理由是什么？
3. 我在担心什么？
4. 什么结果出现，就说明这个判断错了？
5. 哪一天回头看这个决定？

回答完可以直接填进 [[_模板/自我剖析/决策|决策模板]] 的对应字段。

## 一周结束

1. 这周真正完成并留下结果的是什么？
2. 哪件事我一直想做却没做？是什么拦住了我？
3. 这周我对自己的哪个看法被事实支持了，哪个被事实打了折扣？
4. 下周只做一件事，是哪一件？做完能留下什么？

## 方法出处

- 情绪事件那组参考 Gibbs 反思循环（描述、感受、评价、分析、结论、行动计划六个阶段）和“What? So what? Now what?”模型。介绍见爱丁堡大学的 [Reflection Toolkit 资源页](https://institute-academic-development.ed.ac.uk/prog-course-design/reflection/resources) 和 NHS Education for Scotland 的 [Gibbs’ reflective cycle](https://learn.nes.nhs.scot/54509)。
- 复盘那组参考行动后回顾（After Action Review）的四问：原计划、实际发生、差距原因、保留与改进。四问在多个来源中一致；“起源于美国陆军”的说法这次只见于二手资料，待核。
- 目标那组参考 Gabriele Oettingen 的 WOOP（愿望、结果、障碍、计划）。介绍见 [HPRC 的 WOOP 说明](https://www.hprc-online.org/articles/woop-4-simple-steps-to-help-you-achieve-your-goals)。
- “今天没什么可写”“要做一个决定”“一周结束”三组是结合本库的每日、决策和周复盘模板写的，没有外部出处。

以上问题都是改写，不是各方法的原文措辞。

## 用后记录

哪一组问题帮你写出了东西、哪一组没用，在这里各记一行，带日期。有两次以上的记录后，再决定把哪组问题直接写进模板。
