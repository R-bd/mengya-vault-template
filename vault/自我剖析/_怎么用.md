# 自我剖析库 · 怎么用

> 这里不是日记本，是**数据集**。
> 能被剖析的不是你写下的感悟，而是「可重复的字段 × 足够长的时间 × 结局回填」。

整个系统的方向与项目关系见 [[个人成长总览]]；这里负责现实记录、决策回填、能力实验和自我认识修正。

## 一、三个必须同时存在的机制

1. **固定字段** —— 自由文本我能读，但只有固定字段才能跨时间做对比和统计。填不出就留空，别删字段。
2. **结局回填** —— 决策写下后 30/90 天必须回来填「实际结果」。**没回填 = 只有感受，没有真相。**
3. **定期看面板** —— [[剖析面板]] 会自动列出「待回访决策」「情绪分布」，不看等于白记。
4. **能力复测** —— 学会了什么要经过基线与独立复测，见 [[能力提升实验说明]]。

## 三、节奏（别一上来全做）

- **第 1-2 周**：只做 `00 每日` + `01 决策`。别的都不用管。
- **第 3-4 周**：加 `02 情绪事件` + 每周日写一次 [[周复盘]]。
- **第 2 个月起**：开始回填决策结局 —— **真正的剖析从这里才起步**。
- **第 3 个月**：写第一份 [[月复盘]]，开始比较候选模式、反例和适用边界。

## 四、前置设置（一次性）

1. Templater 设置 → Template folder 指向 vault 根目录的 `_模板/`（播客与自我剖析的模板都收在里面，分 `播客/`、`自我剖析/` 两个子目录）
2. 当前已启用 **Periodic Notes**、**Charts** 与 **Dataview**，无需再安装新的追踪插件
3. **不要**把这个 vault 同步到公开的 git 仓库，`06 外部材料` 尤其敏感

## 五、现实预期

| 时间 | 你能得到什么 |
| --- | --- |
| 1-2 周 | 可以分析具体事件，但不能稳定概括长期模式 |
| 1 个月 | 可以提出候选模式，并主动找反例 |
| 3 个月 | 有机会比较决策、习惯和实验结果，但仍取决于回填质量 |
| 6 个月+ | 只有重复验证、反例和边界齐全时，才形成较可靠的个人规则 |

> 条目数量不是可信度保证。具体事件现在就能分析；长期规律必须有重复记录、现实结果和反例。

## 六、方向与能力

- [[个人方向]] 只保留当前最重要的三个重点，周复盘检查时间和结果是否匹配。
- [[能力提升实验说明]] 区分“做过”“AI 帮我完成”和“我能独立完成”。
- AI 或插件发现的模式先记为待验证假设，不直接写成人格事实。

## 七、和播客的关系

播客（[[播客-学习扩展]]）是「学习扩展」这条线的产出，属于剖析范围。
它的产出节奏、卡点位置、选题偏好，都是你认知活动的客观痕迹 —— 见 [[播客产出数据]]。

## 八、和命理的关系

命理材料放在外部材料层，不进入现实事实层。它可以提出候选观察，例如“是否容易只输入不输出”，但不能直接确认人格。候选观察必须在 学校、SRC、播客或日常记录中转成安全、可逆的实验，再由结果和反例判断。详见 [[命理研究入口]]。
