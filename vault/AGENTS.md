# 萌芽知识库路由

把原始材料编译成可追溯、可验证、可修正的知识：种 → 编 → 连 → 用 → 验 → 修。

## 每次开始

1. 读 `_系统/共同规则.md`，全部遵守。
2. 按下表只读需要的技能。不要预读其他规则、整份日志或整份状态 JSON。
3. 需要近期背景时：`tail -n 30 "20 萌芽Wiki/99 变更日志.md"`。
4. 需要课程状态时：`python3 _系统/脚本/状态摘要.py`；判断来源是否已处理用 `--find <路径或哈希>`。

## 路由

| 任务 | 读 |
| --- | --- |
| 整理收件箱、回答知识库问题、健康检查 | `_系统/知识库维护.md` |
| 课程资料、录音、日程、预习、复习、周检 | `学习笔记/课程资料流水线.md` |
| 作业、报告、课程代码 | `学习笔记/作业与代码项目工作流.md` |
| 每周蒸馏 | `每周蒸馏/说明.md` |
| 词义不清 | `CONTEXT.md` |
| 技能之间的关系不清 | `_系统/技能地图.md` |
| 纯翻译、一次性问题 | 只处理指定内容，不启动流程 |

## 底线

原始种子只读。不删文件。不改写用户的记录。不编造。私密资料不外发。AI 产物不算本人结果。

## 结束

Wiki 有改动就同步索引和日志；技能有产物就写一行交接（`_系统/交接/说明.md`）。
