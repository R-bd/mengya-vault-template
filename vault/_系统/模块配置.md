# 模块配置

这页决定萌芽知识库当前启用哪些功能。框架只依赖核心模块；可选模块按个人需要保留、暂停或删除入口。

## 核心模块

| 模块 | 作用 | 主要入口 |
| --- | --- | --- |
| 项目管理 | 登记项目、状态、能力和下一次验证 | [[项目注册表]] |
| 能力实验 | 区分学习、练习、AI 协助和独立掌握 | [[项目能力矩阵]] |
| 证据分级 | 用 E0–E4 管理来源、实践、复现和边界 | [[萌芽知识库运行机制]] |
| 每周蒸馏 | 结转结果、证据、停止项和唯一优先行动 | [[每周蒸馏/说明]] |

## 当前可选模块

| 模块 | 当前状态 | 关闭后的处理 |
| --- | --- | --- |
| 课程学习 | 启用 | 保留历史课程，停止扫描课程目录 |
| SRC 学习 | 启用 | 保留知识卡和实践记录，不安排新验证 |
| 播客 | 启用 | 保留稿件与成品，周报跳过播客检查 |
| 自我剖析 | 启用 | 保留私人记录，停止模式归纳和到期提醒 |
| 命理 | 启用但可忽略 | 当前只镜像案例 001；关闭后不删除材料，周报不读取、不引用，也不生成命理建议 |
| Anki | 启用 | 保留导入记录，停止同步和复习状态检查 |

## 更改规则

- 关闭模块只停止主动维护，不自动删除内容。
- 新模块必须说明入口、证据、隐私边界和停止条件。
- 每周蒸馏只检查这里启用的模块和 [[项目注册表]] 中状态为“进行中”的项目。
- 命理即使启用，也只能作为传统文化材料和候选假设；个人不信时可以完全忽略，不影响其他模块。
