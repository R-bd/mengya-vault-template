# 隐私边界

这个仓库只放框架：规则页、模板、流程说明、两个自写技能和脚本。下面这些不属于框架，不要提交到公开仓库。

## 只在自己的设备间同步

课程资料和原始文件、作业和成绩、课堂录音和转写、周报、Wiki 的实际内容、状态文件、备份，以及任何其他人的资料。

## 只留在单台电脑上

口令和钥匙串、浏览器登录会话和 Cookie、采集程序及其配置、代理工具的配置和记忆、Obsidian 的工作区状态和插件数据。

## 从自己的库导出框架时

1. 写一份导出清单和一份替换表，把姓名、学号、学校名、课程代码、本机路径换成占位符。两份文件都放在仓库之外。
2. 运行 `scripts/export_framework.py` 导出。
3. 运行 `scripts/scan_private.py --terms <私有词表>` 扫描。有命中就先处理，不要提交。
4. 推送前亲自看一遍 `git ls-files` 列出的文件清单。

替换只能处理写得出来的词。带有个人经历、具体日期和具体事件的段落，要人工读一遍再决定删改。
